# Omnibot

This is a personal project I am developing for fun.

This is a repo for an autonomous robot using mecanum drive so it can drive in any direction.

To start the system run "start.sh", this will launch a docker container, rviz, and a sim world with a mecanum robot in it.

I am developing this project to run on a Jetson Orin Nano to control a physical robot. Using ROS2 Lyrical, and Nav2.
